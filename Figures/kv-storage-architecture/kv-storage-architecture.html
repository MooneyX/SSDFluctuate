ARCHITECTURE / OPTION B

低抖动 KV 存储架构

存储侧可采用 DPU 或 CPU + RNIC，实现 KV 调度与传输。共同优化目标：抑制抖动、降低端到端延迟、提高有效带宽。

双向总览实线展示 KV 数据主路径；虚线区分控制面与可选缓存。节点数量可扩展，当前展示一条端到端路径。
01 / 存储侧

统一服务，两种实现

DPU：处理器与集成网络引擎协同调度和传输。CPU + RNIC：CPU 运行存储软件，RNIC 承担 RDMA 收发，主机 DRAM 可作为 I/O 缓冲。两者均可配置 KV 缓存与预取。

02 / 推理侧

网卡通过 PCIe 直达 HBM

RNIC 通过 GPUDirect RDMA，经 GPU 的 PCIe 接口访问 HBM。CPU 与推理运行时负责控制，通过完成通知与可见性同步协调 KV 就绪和计算启动。

03 / 优化目标

低抖动、低延迟、高有效带宽

SSD 放置与读写隔离、存储服务限流与跨盘选路、推理运行时预取协同优化。以 SSD→HBM 的 P99/P99.9 延迟、GPU 等待时间和有效 GB/s 衡量两种实现。
